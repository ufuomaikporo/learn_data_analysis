# Finance Data Analyst — Learning Roadmap

**Goal:** Prepare for Canadian finance data analyst, finance BI, banking data, revenue analyst, and financial reporting roles. **Pace:** 36 weeks at 8–10 hours per week (roughly 8–9 months), based on the [Canada career guide](reference_souces/Finance_Data_Analytics_Career_Guide_Canada_Updated.md). This is a learning plan, not a job or salary guarantee.

The plan assumes basic finance familiarity and limited analytics experience. Use the baseline in the tracker to adjust; if accounting is new, add time for financial statements before Week 1. Start applying once your evidence and target postings support it; do not wait for a certificate.

## Start here

1. Review the [glossary](06-glossary.md) and [dataset definitions](data/README.md), complete the baseline, and install only the tools needed for Phase 1.
2. Start the [Week 1–4 schedule](weekly-schedules/phase-01-excel-finance.md) and its [lab workbook](labs/phase-01-excel-finance.md).
3. Reserve 8–10 hours a week; use selected course sections rather than trying to finish every course.
4. Store your work separately from raw inputs, record assumptions and quality checks, and publish only synthetic or permitted public data. Label project work as independent practice.

## Principles

- Finance definitions and data quality come before charts; reconcile the same figures across tools.
- Use W3Schools first for Excel, SQL, statistics, Python and pandas. For Power BI, start with Microsoft Learn because an official W3Schools Power BI tutorial was not verified. Use Udemy and official documentation to fill gaps and clarify versions.
- Build two distinct but related projects: a SQL + Power BI finance dashboard and an Excel + Python financial-performance analysis.
- Treat the tiny starter dataset as a learning fixture, not evidence about real banks or customers. Projects must state their sample and limitations.
- Do not use proprietary data, personal information, invented business impact, or financial recommendations presented as professional advice.
- Canadian market conditions and credential requirements change: check current postings and official sources rather than relying on fixed salary claims.
