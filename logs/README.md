# Weekly Logs

Use the separate file for each week to record decisions or questions, assumptions when needed, findings and limitations, self-check answers, and next actions. State only genuine assumptions: if the data contract or a stakeholder already defines a value or rule, record it as a definition rather than an assumption. If there are no assumptions, write “None; used the stated definitions.” Each file contains four self-check questions. Answer from memory; the final question names that week's concepts and asks how you would apply them as a data analyst in the real world, with an example and explanation. Fill it in during the week and review it on Day 5. The [study tracker](../05-study-tracker.md) remains the home for the baseline, milestones, and phase gates.

For an example of how to fill in the weekly record fields, see the [filled-out Week 1 example](example-weekly-record.md). It uses the fictional practice dataset; replace the sample notes with your own work.
