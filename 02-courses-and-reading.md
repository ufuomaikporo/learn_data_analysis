## Study order and selection

Use **W3Schools** as a primary source where its tutorials cover the topic, then do the assigned lab. Use the named Udemy course for a different explanation or deeper practice and official documentation for the exact tool, current behavior and uncovered topics. Select only the relevant topics within the scheduled study blocks; the full courses are **not** required or extra hours. The weekly schedules map lessons to each phase and week.

Finance concepts are an exception to W3Schools-first when no suitable coverage is provided: use [OpenStax on the income statement](https://openstax.org/books/principles-finance-2e/pages/5-1-the-income-statement), [Boise State on budget versus actual](https://boisestate.pressbooks.pub/bsumbaaccounting/chapter/7-2-comparing-budget-to-actual/) and the roadmap's [finance definitions](data/README.md). The fixture's simplified profit is not a complete income statement.

## Targeted references for labs

- **Excel zero-denominator logic:** [W3Schools Excel IF Function](https://www.w3schools.com/excel/excel_if.php) and [Microsoft IF function](https://support.microsoft.com/en-us/excel/functions/if-function).
- **SQL zero-denominator logic:** [SQLite NULLIF function](https://www.sqlite.org/lang_corefunc.html#nullif).
- **DAX zero-denominator logic:** [Microsoft DAX DIVIDE function](https://learn.microsoft.com/en-us/dax/divide-function-dax).
- **Concise business memos:** [Purdue OWL memo format and sample](https://owl.purdue.edu/owl/subject_specific_writing/professional_technical_writing/memos/format.html).
- **Python undefined values:** [Python built-in constants](https://docs.python.org/3/library/constants.html#None).

W3Schools tutorials and practice examples are generally free; certificates and optional training products may cost money. Udemy course prices, subscriptions, titles and availability vary. Inspect the syllabus and preview before paying; do not assume any course is included in a subscription. W3Schools and Udemy can restrict automated access; if blocked, open the link in a browser and use the relevant documentation if necessary.

## Setup and cost

- Free [Excel for the web](https://excel.cloud.microsoft/) can support the core spreadsheet exercises. For Power Query, feature and license availability differs: Microsoft's [web Power Query guidance](https://support.microsoft.com/en-us/excel/use-power-query-in-excel-for-the-web) distinguishes subscriber and business/enterprise functionality. Use the documented manual web alternative in the Phase 1 lab if you cannot create or edit queries, and label it as a substitute rather than Power Query experience. Power BI Desktop provides a separate place to practise Power Query. Desktop Excel features vary by version and license; if XLOOKUP is unavailable, use INDEX/MATCH and document the substitution.
- [Power BI Desktop](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop) is a Windows desktop download. Desktop work can remain local; publishing/sharing may require a qualifying account or license. Screenshots and an explanatory walkthrough are enough for a public portfolio; never upload sensitive data.
- [SQLite](https://www.sqlite.org/download.html), [Python](https://www.python.org/downloads/), pandas and Jupyter can run locally; use a virtual environment and document installed versions. See the [JupyterLab notebook documentation](https://jupyterlab.readthedocs.io/en/latest/user/notebook.html). No cloud account is required.
- Budget time and any software/course costs before committing. Do not assume a Udemy course is part of a particular subscription.
