# Weekly Study Schedules

[Overview](../README.md) · [Glossary](../06-glossary.md) · [Labs](../labs/README.md) · [Course resources](../02-courses-and-reading.md)

Each schedule uses the same **9-hour week**: Day 1 is 1 hour, Day 2 is 1.5 hours, Day 3 is 1.5 hours, Day 4 is 3 hours, and Day 5 is 2 hours. Lessons, labs, reviews, and project work all fit inside those blocks. Select the named topics in the linked resource; course sections may change.

Each day links to material relevant to its study or practice, alongside the week's lab. Read only the sections needed for that day's topic; the resources are not additional hours or a requirement to finish entire textbooks, learning paths, or courses. W3Schools is the first choice where it covers the topic; official documentation and other materials fill subject-specific gaps. The day-by-day schedule avoids repeating a secondary link when the primary source already covers the same topic; the full primary and supplementary resource map is in [Courses and Reading](../02-courses-and-reading.md). For practice-only tasks, the lab and project references are the instructions rather than a separate course.

Each week opens with the goal, learning outcomes and day-to-day use on separate lines.

### How lab and project work fit

- **Lab exercise:** Follow the guided practice steps for the day's topic. Some lab outputs are reused in a project when its brief says so; the lab remains the single scheduled activity.
- **Project Work:** Use this section only for a distinct project application, review or milestone that is not already the lab task. Do not list the same activity in both sections.
- **Lab-only day:** Practice or review; there is no separate Project Work task.
- **Project Work-only day:** A standalone project task, review or milestone, such as a rubric review or packaging task.
- **End-of-week and phase gates:** Integrate, reconcile and verify the components completed so far; they are not a second pass through every lab.

The project briefs define the final portfolio deliverables, while labs provide guided steps to build and check them incrementally. Interview-practice days may link to project briefs for context without assigning project deliverables.

Project progression: Phases 1, 4 and 5 feed [Project B](../projects/project-b-excel-python.md); Phases 2 and 3 feed [Project A](../projects/project-a-sql-power-bi.md); Phase 6 audits and packages both. Phase 6 lab-only interview and career exercises are practice, not project deliverables.
